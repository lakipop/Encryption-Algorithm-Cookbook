# Encryption Algorithm Cookbook

This repository contains simple Java implementations of several basic encryption algorithms, as described in the provided lab sheets.

Each algorithm is contained in its own directory and includes:
- A `README.md` file explaining the theory behind the algorithm with an example.
- A `<AlgorithmName>.java` file with a simple, commented implementation that can be run.
- An `<AlgorithmName>Answer.java` file containing the sample answer from the lab sheet.

## Algorithms Included
- Caesar Cipher
- ROT13
- Atbash Cipher
- Vigenère Cipher
- Rail Fence Cipher
